# Actividad de la versión de Workfront Fusion: Semana del 19 de octubre de 2026

Esta página describe todas las mejoras realizadas en Adobe Workfront Fusion durante la semana del 19 de octubre de 2026.

Para obtener una lista de todos los cambios recientes, consulte [Actividad de la versión de Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Para obtener una lista de las correcciones de errores recientes en Workfront Fusion, consulte la página [Actualizaciones de mantenimiento de Workfront](https://experienceleague.adobe.com/es/docs/workfront-known-issues/releases/current-updates) y busque cualquier actualización etiquetada como Actualización de mantenimiento de Workfront Fusion.

## Nuevas variables de asignación

Seis nuevas variables generales ya están disponibles en el panel Asignación. Proporcionan vínculos de ejecución y escenarios listos para usar, direcciones URL de API e identificadores de propiedad, de modo que puede incluir estos valores en campos asignados sin crear direcciones URL ni codificar los ID de organización y equipo.

* `scenarioUrl`: un vínculo al escenario actual en la interfaz de usuario de Fusion.
* `executionUrl`: un vínculo a la ejecución del escenario actual en la interfaz de usuario de Fusion.
* `scenarioApiUrl`: URL de la API de Fusion para el escenario actual.
* `executionApiUrl`: URL de la API de Fusion para los detalles de la ejecución actual.
* `teamId`: ID del equipo de Fusion que posee el escenario actual.
* `organizationId`: ID de la organización de Fusion asociada con la ejecución actual.

Estas variables amplían las variables existentes `executionID`, `scenarioID`, `scenarioName`, `triggerTimestamp` y `operationsConsumed`.

Para obtener más información, consulte [Funciones generales](/help/workfront-fusion/references/mapping-panel/functions/general-functions.md).

## Cambios en el conector Fusion

El conector de Workfront Fusion ahora admite más acciones para administrar su organización de Fusion desde un escenario concreto.

**Nuevos módulos y acciones**

* **Clonar un registro:** Ahora puede clonar un enlace. Utilice dependencias para asignar las dependencias del vínculo de origen al destino, como lo hace al clonar un escenario.
* **Eliminar un registro:** Ahora puede eliminar una conexión, almacén de datos, registro de almacén de datos, registros de almacén de datos (masiva), estructura de datos, vínculo, clave, escenario o equipo.
* **Enumerar registros:** Ahora puede enumerar DLQ, organizaciones, equipos y usuarios.
* **Leer un registro:** Ahora puede leer un DLQ, la organización actual, un equipo, un usuario o el usuario autorizado.
* **Obtener dependencias de registros:** Ahora puede obtener las dependencias de un vínculo.
* **Obtener dependientes de registros:** Este nuevo módulo devuelve los dependientes de almacenes de datos, enlaces y escenarios. Ejecútelo antes de eliminar un recurso para comprobar si algo depende de él.

**Otras actualizaciones**

* Los filtros de propiedad marcados como de varios valores ahora aceptan valores separados por comas con los operadores `==` y `!=`. Actualmente, solo la propiedad `id` de los usuarios admite esto (por ejemplo, `id==123,456`).
* Al eliminar una cola de ganchos, el parámetro `except` reemplaza a `excludeId` y solo se puede usar al eliminar todos los elementos. El parámetro `id` ahora acepta una lista separada por comas. Se devuelve una nueva respuesta 423 cuando ya hay una eliminación en curso.
* Al obtener escenarios o un solo escenario, ahora puede utilizar el parámetro `fields` para elegir qué campos se devuelven.

Para obtener más información, consulte [Módulos de Workfront Fusion](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md).

## Conector MCP de Adobe Fusion

El nuevo conector MCP de Adobe Fusion le permite enviar un mensaje en lenguaje natural al servidor MCP de Adobe Fusion desde un escenario concreto. Un modelo de lenguaje grande (LLM) interpreta su solicitud y llama a las herramientas de Fusion necesarias para completarla.

El conector solo funciona con el punto final MCP de Adobe Fusion alojado.

Para obtener más información, consulte [Módulos MCP de Adobe Fusion](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-fusion-mcp-modules.md).
