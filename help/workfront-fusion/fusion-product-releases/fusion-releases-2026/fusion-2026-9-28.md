# Actividad de la versión de Workfront Fusion: Semana del 28 de septiembre de 2026

Esta página describe todas las mejoras realizadas en Adobe Workfront Fusion durante la semana del 28 de septiembre de 2026.

Para obtener una lista de todos los cambios recientes, consulte [Actividad de la versión de Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Para obtener una lista de las correcciones de errores recientes en Workfront Fusion, consulte la página [Actualizaciones de mantenimiento de Workfront](https://experienceleague.adobe.com/es/docs/workfront-known-issues/releases/current-updates) y busque cualquier actualización etiquetada como Actualización de mantenimiento de Workfront Fusion.

## Actualizaciones en el conector de Marketo

Para permitirle interactuar con extractos masivos en Marketo, hemos añadido tres módulos nuevos:

* Creación de un trabajo de extracción masiva
* Obtener estado del trabajo de extracción masiva
* Descargar un archivo de extracción masiva

Además, también hemos agregado la capacidad de agregar un cuerpo de solicitud JSON sin procesar en el módulo Llamada de API personalizada.

Para obtener más información, consulte [módulos de Marketo](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-marketo-modules.md).

## Conecte Fusion a su agente de IA con el conector Fusion MCP

Para permitirle utilizar Adobe Workfront Fusion con agentes de IA, hemos creado un servidor MCP de Workfront Fusion. Ahora puede utilizar este servidor para inspeccionar escenarios, revisar ejecuciones, administrar conexiones y realizar acciones aprobadas con los permisos de Fusion existentes. Esto facilita el trabajo con Fusion en lenguaje natural sin abandonar la experiencia de agente.

Para obtener más información, consulte [Configuración del servidor MCP de Adobe Workfront Fusion](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-fusion-mcp-server/configure-fusion-mcp-server.md).

## Nuevo conector MCP de Adobe Marketo Engage

Ahora puede conectar Workfront Fusion directamente al servidor MCP de Adobe Marketo Engage mediante el nuevo conector MCP de Adobe Marketo Engage.

Ahora, puede introducir una instrucción de inglés sin formato y de composición abierta, y un modelo de IA decide qué acciones de Marketo son necesarias para cumplirla.Puede restringir qué acciones de solo lectura y de escritura/eliminación puede realizar la IA, de modo que incluso un escenario desatendido se pueda limitar a las acciones que apruebe.

El módulo puede utilizar el servicio de IA administrado de Adobe de forma predeterminada, o su propia clave OpenAI, Anthropic Claude o Amazon Bedrock, si lo prefiere.

Para obtener más información, consulte [Módulo MCP de Adobe Marketo Engage](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-marketo-engage-mcp-module.md).
