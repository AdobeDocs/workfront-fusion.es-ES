# Actividad de la versión de Workfront Fusion: Semana del 7 de septiembre de 2026

Esta página describe todas las mejoras realizadas en Adobe Workfront Fusion durante la semana del 7 de septiembre de 2026.

Para obtener una lista de todos los cambios recientes, consulte [Actividad de la versión de Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Para obtener una lista de las correcciones de errores recientes en Workfront Fusion, consulte la página [Actualizaciones de mantenimiento de Workfront](https://experienceleague.adobe.com/es/docs/workfront-known-issues/releases/current-updates) y busque cualquier actualización etiquetada como Actualización de mantenimiento de Workfront Fusion.

## Nuevos tipos de autorización para los webhooks personalizados

Ahora puede autorizar los webhooks personalizados con dos nuevos métodos: autenticación de clave de API y firma HMAC. La autenticación de clave de API es ahora el tipo de autorización predeterminado para los nuevos webhooks. Los tipos de autorización anteriores siguen estando disponibles y puede seleccionar el valor vacío para la opción sin autorización.

Para obtener más información, consulte [Webhooks](/help/workfront-fusion/references/apps-and-modules/universal-connectors/webhooks-updated.md).
