# Actividad de la versión de Workfront Fusion: Semana del 7 de septiembre de 2026

Esta página describe todas las mejoras realizadas en Adobe Workfront Fusion durante la semana del 7 de septiembre de 2026.

Para obtener una lista de todos los cambios recientes, consulte [Actividad de la versión de Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Para obtener una lista de las correcciones de errores recientes en Workfront Fusion, consulte la página [Actualizaciones de mantenimiento de Workfront](https://experienceleague.adobe.com/es/docs/workfront-known-issues/releases/current-updates) y busque cualquier actualización etiquetada como Actualización de mantenimiento de Workfront Fusion.

## Nuevos tipos de autorización para los webhooks personalizados

Ahora puede autorizar los webhooks personalizados con dos nuevos métodos: autenticación de clave de API y firma HMAC. La autenticación de clave de API es ahora el tipo de autorización predeterminado para los nuevos webhooks. Los tipos de autorización anteriores siguen estando disponibles y puede seleccionar el valor vacío para la opción sin autorización.

Para obtener más información, consulte [Webhooks](/help/workfront-fusion/references/apps-and-modules/universal-connectors/webhooks-updated.md).

## Nuevo botón Describir con IA en la descripción del escenario

Ahora puede hacer clic en Describir con IA en el campo de descripción del panel Configuración de un escenario para que AI genere una descripción del escenario automáticamente, según los módulos y la configuración del escenario.

Para obtener más información, consulte [Configurar opciones de escenario](/help/workfront-fusion/create-scenarios/config-scenarios-settings/configure-scenario-settings.md#description).

## Conector MCP de Fusion AEM

Envíe un mensaje en inglés sin formato al servidor MCP (Model Context Protocol) de Adobe Experience Manager y deje que un modelo de IA decida qué acciones de Adobe Experience Manager son necesarias para llevarlo a cabo. Este nuevo conector dedicado agrega un solo módulo, Procesar una solicitud de usuario, que:

* Se conecta a Adobe Experience Manager mediante OAuth: no se requieren credenciales manuales.
* Interpreta las instrucciones y llama a las acciones de Adobe Experience Manager necesarias (sitios, recursos, fragmentos de contenido, carpetas, el repositorio de contenido y la IA de contenido) para cumplirlas.
* Permite restringir las acciones de solo lectura y escritura/eliminación que la IA puede realizar, de modo que incluso un escenario desatendido no puede realizar una acción destructiva inesperada.
* Utiliza el servicio de IA propio de Adobe de forma predeterminada o su propia clave de OpenAI, Anthropic Claude o Amazon Bedrock, si lo prefiere.

Para obtener más información, consulte [Módulos MCP de Adobe Experience Manager](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/aem-mcp-modules.md).

## Nuevo módulo Escenarios de exportación en el conector Workfront Fusion

El conector Workfront Fusion ahora incluye un módulo Exportar escenarios, que le permite exportar el modelo para uno o más escenarios directamente desde un escenario.

Para obtener más información, consulte [Módulos de Workfront Fusion](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md).

## Definir tokens personalizados en los módulos de déclencheur instantáneo de Workfront y Workfront Planning

Para que los webhooks de Workfront sean más flexibles y seguros, hemos creado la capacidad de añadir tokens personalizados. Ahora puede proporcionar su propio valor de token para proteger los enlaces web en el módulo Workfront > [!UICONTROL Ver eventos] y en el módulo Workfront Planning > [!UICONTROL Ver eventos (V2)]. Anteriormente, Fusion siempre generaba este token automáticamente. Si deja en blanco el nuevo campo [!UICONTROL Token personalizado], Fusion seguirá generando el token por usted.

Para obtener más información, vea [Módulos Workfront y sus funciones](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-modules.md) y [Módulos Workfront Planning y sus funciones](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-planning-modules.md).
