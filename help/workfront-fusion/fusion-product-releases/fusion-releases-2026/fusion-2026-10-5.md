# Actividad de la versión de Workfront Fusion: Semana del 5 de octubre de 2026

Esta página describe todas las mejoras realizadas en Adobe Workfront Fusion durante la semana del 5 de octubre de 2026.

Para obtener una lista de todos los cambios recientes, consulte [Actividad de la versión de Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Para obtener una lista de las correcciones de errores recientes en Workfront Fusion, consulte la página [Actualizaciones de mantenimiento de Workfront](https://experienceleague.adobe.com/es/docs/workfront-known-issues/releases/current-updates) y busque cualquier actualización etiquetada como Actualización de mantenimiento de Workfront Fusion.

## Conector Jira: nuevos tipos de conexión de cuenta de servicio

Para facilitar la creación de conexiones Jira que coincidan con la forma en que su equipo se autentica, hemos añadido dos nuevos tipos de conexión al conector Jira: token de API de cuenta de servicio y cuenta de servicio OAuth 2.

Estas opciones le permiten crear conexiones para la automatización que deben ejecutarse como una cuenta de servicio Jira dedicada en lugar de una cuenta de usuario personal. Utilice el token de API de cuenta de servicio cuando su cuenta de servicio Jira se autentique con un token de API y utilice la cuenta de servicio OAuth 2 cuando su entorno utilice OAuth 2 para la cuenta de servicio.

Los tipos de conexión básica y OAuth2 siguen estando disponibles.

Para obtener más información, consulte [Módulos Jira](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/jira-modules-new.md).

## Nuevo Módulo Crear varias anotaciones disponible para el conector Veeva Vault

Para que el módulo Crear varias anotaciones sea más fácil de usar, lo hemos actualizado a un nuevo módulo. Ahora puede seleccionar campos para marcadores de posición, referencias y otros campos de anotaciones antes de proporcionar valores, lo que simplifica la configuración y se centra únicamente en los valores que prioriza.

El módulo Crear varias anotaciones disponible anteriormente sigue disponible, marcado como &quot;Heredado&quot;.

Para obtener más información sobre los módulos de Veeva Vault, consulte [Módulos de Veeva Vault](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/veeva-vault-modules.md).

## Añadir autenticación JWT firmada a solicitudes HTTP con el módulo HTTP > Crear una solicitud JWT

Para facilitar las llamadas a las API que requieren autenticación JWT firmada, hemos añadido el módulo de solicitud HTTP > Crear un JWT.

Este módulo funciona como el módulo estándar HTTP > Crear una solicitud, pero genera y firma automáticamente un token web JSON a partir de las notificaciones que proporcione y lo incluye en la solicitud, de forma predeterminada como token de portador de autorización. Esto le ayuda a autenticarse en servicios que requieren acceso basado en JWT de corta duración sin crear un paso independiente de generación de tokens en su escenario.

Para obtener más información, consulte [HTTP > Crear un módulo de solicitud JWT](/help/workfront-fusion/references/apps-and-modules/universal-connectors/http-module-make-a-jwt-request.md).
